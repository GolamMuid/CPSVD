## Downloading embedding

1. Go to embedding folder
2. Run download_primevul_emb.py file. It will download a zip file named as primevul.zip
3. Unzip the zip file.

## Running Scripts

1. Go to tests > synthetic oversampling
2. Run all the scripts from primevul_s1 > codet5
3. Run all the scripts from primevul_s2 > codet5
4. Run all the scripts from primevul_s3 > codet5
5. Run all the scripts from primevul_s4 > codet5
